# LiveTrustScore

LiveTrustScore is a web application that analyzes the trustworthiness of a given URL using four scientific analysis models and returns a final LiveTrust Score (0–100).

This project is a Next.js application bootstrapped with `create-next-app`.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
